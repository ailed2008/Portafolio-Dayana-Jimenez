Plataforma E-Commerce
Descripción del Proyecto

Desarrollo colaborativo de una plataforma web e-commerce orientada a la experiencia de usuario y consumo de servicios backend. La aplicación gestiona el catálogo de productos, carrito de compras y la integración fluida entre la interfaz y la API.

Funcionalidades & Desarrollo Backend
  • Consumo de APIs REST: Conexión entre la interfaz web y endpoints desarrollados en Java Spring Boot usando Fetch API / JavaScript.
  • Catálogo Dinámico: Renderizado de productos, filtros por categoría y gestión en tiempo real del carrito de compras.
  • Diseño Adaptativo: Maquetación UI/UX mobile-first utilizando componentes de Bootstrap 5 para garantizar compatibilidad multidispositivo.
  • Trabajo Colaborativo: Control de versiones estructurado mediante ramas (Git Feature Branch Workflow) e integración de cambios en GitHub.
